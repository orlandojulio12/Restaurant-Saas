# Skills del proyecto

Instrucciones que Claude Code carga cuando la tarea encaja con su descripción.
Viven aquí dentro para que viajen con el repositorio y todo el que clone tenga
las mismas.

| Skill | Origen | Licencia |
|---|---|---|
| `frontend-design` | [anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/frontend-design) | Apache 2.0 |

Una skill es texto que el agente acaba siguiendo, así que conviene leer lo que
se añade antes de instalarlo y preferir fuentes que se puedan verificar.
